# 发现页轮播广告

发现页活动网格开头、末尾各放一个跨两列的广告位，随内容滚动。搜索和筛选工具栏保留；底部广告位于当前已加载活动之后，继续分页时会向后移动，不是固定悬浮层。空列表、加载和错误状态也保留广告位。

## 配置

编辑 `android/app/src/main/assets/ads.json`，重新构建安装。当前实现是本地配置，不支持远程更新；没有新增官方接口或广告 SDK。

```json
{
  "showPlaceholders": true,
  "top": [
    {
      "id": "top-001",
      "title": "校园推广",
      "imageUrl": "https://你的域名/top.jpg",
      "targetUrl": "https://你的域名/campaign",
      "enabled": true
    }
  ],
  "bottom": [
    {
      "id": "bottom-001",
      "title": "更多优惠",
      "imageUrl": "https://你的域名/bottom.jpg",
      "targetUrl": "https://你的域名/offers"
    }
  ]
}
```

上面是配置格式示例，域名和素材需要替换。图片要求 HTTPS，目标链接支持 HTTP/HTTPS；条目按数组顺序展示，同一位置的 id 必须唯一。无效或禁用条目会被跳过。

- 顶部建议 1080×360，底部建议 1080×420；图片按比例裁切铺满。
- 多张广告每 5 秒轮播，可左右滑动，提供暂停/继续按钮；单张不自动切换。
- 应用进入后台或切换其他主标签后停止自动播放。
- `showPlaceholders: true` 时，空广告位显示预留板块；设为 false 则隐藏空位置。
- 图片加载失败时展示广告标题，仍可点击打开链接。
- 所有广告链接均交给系统浏览器，不经过会注入官方账号资料的网页容器。
- 广告配置与图片请求不附带官方 token，不采集曝光或点击统计。

## 验收

安装 debug APK 后检查首尾位置、单张/多张广告、点击返回、无浏览器、断网、深色模式、搜索无结果、分页和主标签横向手势。当前提交的广告数组为空，只展示预留位置，不包含真实投放素材。
