# 文档索引

本目录随仓库提交，只放**我们自己写、且经过验证**的内容。

| 目录 | 内容 |
| --- | --- |
| `decisions/` | 架构与工程决策记录（ADR），编号递增，一经采纳不删除，只追加「被替代」 |
| `api/` | 对官方站点接口的实测结论，每条注明验证日期与所用方法 |

`docs/_local/` 已被 `.gitignore` 忽略，用于放置第三方参考原文、抓包草稿等不便入库的材料。

## 约定

- 文档用中文，标题层级最多三级。
- 任何接口结论必须写清：验证日期、请求方式、返回码。
- 不记录真实学号、姓名、token、密码。
