# 0002 登录：固定学校、不存密码、token 加密落盘

- 状态：已采纳
- 日期：2026-10-21

## 背景

官方接口在未登录时一律返回 `code:10001`，登录不可绕过；登录接口无验证码、无签名，
`POST /token` 返回 JWT，后续请求以 `Authorization: <裸 JWT>` 鉴权。

## 决策

1. **不做学校选择**：本应用只服务安徽理工大学，登录页固定 `schoolCode=10361`。
   `School` 保留为数据类并登记在 `School.all`，将来拓展学校时只改数据与上层选择，登录页逻辑不变。
   隐藏入口：登录页长按校名 5 秒进入选校页（数据来自官方 `/common/all-school`），
   用于验证多学校扩展，不占据正常流程。
2. **不保存密码**：密码只在登录请求中发送至官方站点，应用内不落盘、不写日志。
3. **token 加密存储**：JWT 与个人信息使用 Android Keystore 中的 AES-256/GCM 密钥加密后存入
   SharedPreferences；退出登录即删除。
4. **不缓存明文响应**：接口响应只在内存中解析，不写入文件。

## 后果

- 卸载重装或清除数据后需要重新登录。
- 若官方 JWT 失效，原生页需能跳回登录页（后续实现统一拦截）。
- 多学校扩展不需要改动网络层与登录页，只需要增加 `School` 条目与入口。
