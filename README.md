# 二课++

> **声明**：本软件是安徽理工大学「第二课堂」（官方站点 <https://win.9xueqi.com>）的**非官方客户端**，与学校及平台方没有隶属关系。它不伪造、不绕过官方数据，只是把你手机浏览器里发生的请求用原生界面重做了一遍——登录、报名、签到仍然走官方接口。
>
> **注意**：本软件仅供学习交流。任何破解行为与本人无关。使用本软件造成的不良影响需自行承担（虽然目前还没发现什么不良影响）。

## 软件介绍

官方功能我们基本都有，对日常痛点，针对性地进行体验优化和功能补充。

### 基础功能

- **活动列表直显**：列表直显学时、人数（已报人数/总人数）及截止时间，减少详情页点击次数
- **个人数据看板**：原生展示学分、学时与诚信值，提供「诚信值」「我的附件」统一入口
- **诚信值**：分数、等级、待守约 / 已守约 / 已失约 / 申诉记录，规则弹窗一屏看完
- **扫码签到**：首页「扫一扫」与详情页「扫码签到」共用一套相机，签到码、活动分享码、组织码分开处理
- **组织**：「我的」里的我的组织（三个列表 × 三种审核状态）、「更多」里的所有组织目录，
  组织码扫开就是详情，能直接申请加入
- **应用内更新**：设置 → 关于 → 检查更新，下载完直接拉起系统安装器

### 体验优化

- **主页全量平铺**：主页直接平铺所有活动，而不是折叠到某个角落里。
- **登录长效保持**：一次登录长久有效。
- **多维度筛选**：支持按学时、热度、状态、分类筛选，还能只看已报名。
- **全文搜索**：官方 `search` 参数只影响总数，所以客户端把列表拉全后本地匹配，多个关键词用空格分隔。
- **详情页重构**：区块化显示关键信息，包括学时、时间、限制条件（学院/诚信分等），无需二次点击。
- **状态按时间算**：报名中 / 待报名 / 待开始 / 进行中 / 已结束，官方编号再变也不会标错。
- **成绩排行榜**：点「我的」页的学分卡片，看班级 / 专业 / 院系 / 全校排名，自己那一行会有标记。
- **人物主页**：排行榜前三名、榜内每一行、组织负责人，点进去能看到对方的学院班级、参加活动与加入组织数、个人标签，还能直接关注
- **丰富交互体验**：专门优化暗色模式（拯救夜间核爆现场🙃）。支持预加载列表（让加载快人一步）。三大主页支持左右滑动，无缝切换。适配了安卓预测性返回动画。

### 特色功能

- **内容屏蔽**：支持关键字屏蔽、正则屏蔽。拯救您的注意力。
- **自定义卡片**：可自定义卡片内容：封面、标签、学时、人数 等，还支持自定义标题行数。
- **附件管理**：支持列表/网格视图切换，内置图片预览，新增回收站防误删，支持一键分享。
- **数据管理**：缓存、日志、网页数据、附件回收站的占用一目了然，可逐项勾选清理，默认只勾安全项。
- **二维码分享**：详情页支持生成分享二维码，方便转发分享。
- **发现页推广位**：列表首尾预留轮播广告位，由本地配置提供图片及链接，不接入广告 SDK 或第三方统计。
- **安全加密**：不保存密码。登录凭证用 Android 系统密钥库（AndroidKeyStore）派生的密钥加密后再落盘，明文只存在于内存里。

## 使用前须知

| 项 | 说明 |
| --- | --- |
| 系统要求 | Android 8.0（API 26）及以上，targetSdk 36 |
| 已测机型 | 24090RA29C（Android 16 / API 36） |
| 切换学校 | 登录页**长按校名 5 秒**进入选校页。针对安徽理工大学优化，其他学校能选能登，但没有验证过 |
| 相机权限 | 只用于扫码签到与扫一扫，不采集、不上传画面 |
| 安装权限 | 应用内更新需要「安装未知应用」，只在下载完成后申请 |
| 文件位置 | 附件下载到 `Download/ErkePlus/`，更新包缓存在应用私有目录 |
| 版本 | 当前 0.9.0，更新内容见 [CHANGELOG.md](CHANGELOG.md) |

几条线上踩出来的边界，先说清楚免得白点：

- 「全部」只含已发布的活动。未审核的活动官方界面不展示、也没有报名入口，待报名的连列表接口都不返回，细节见 [术语库](GLOSSARY.md)
- 团队报名、需要填写报名材料的活动，客户端只给「在官方页面查看」，不在本地造半成品表单
- 官方接口没有公开文档，随时可能变；真变了不一定能及时修好，请以官方页面为准

## 隐私与安全

- **不保存密码**：只在登录那一刻用一次，不落盘、不写日志
- **登录凭证加密落盘**：用 AndroidKeyStore 派生密钥加密后才写进本地文件，密钥不出系统密钥库
- **不参与备份**：`allowBackup=false`，备份与设备迁移规则里排除了全部目录，换机不会带走登录态
- **不记录请求**：没有 HTTP 日志拦截器，请求头不会进 logcat 或应用日志；应用日志里也不写 token
- **无统计 SDK**：没有第三方统计或崩溃上报；配置推广内容后会访问对应图片地址，点击链接交给浏览器；附件与更新包只存在本机
- **token 在内存里必然是明文**：请求头里就要放它，这一点无法避免；防线是让它不出现在文件、剪贴板、日志和界面上
